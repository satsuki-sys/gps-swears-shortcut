A make.fun entry for **The GPS Swears It Was a Shortcut** — write the GPS's
one line excuse for sending the driver down the wrong road.

`main.py` writes the excuse — one line of plain text, at most 200 characters —
to `/output/entry.txt`:

> I didn't miss the turn, I upgraded it — the map swore the lake was a
> shortcut, the wedding waved us through, and the ducks have never seen a
> sedan before.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
